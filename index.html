Maîtriser Git et GitHub : les bases de la collaboration moderne

Une formation pratique pour utiliser Git et GitHub avec confiance, seul ou en équipe.

  • Niveau : débutant
  • Durée : deux jours
  • Présentiel
  • Langue : français
  • Tarif : 56,00 €
  • Certificat de participation

À propos

Git est souvent perçu comme complexe. Cette formation le présente de manière claire et concrète : vous apprendrez à suivre les modifications d'un projet, à travailler en équipe, à gérer les branches et à utiliser les Pull Requests. L'objectif : faire de Git un outil du quotidien pour un travail collaboratif fluide.

Public visé

  • Développeurs
  • Designers
  • Professionnels techniques

Prérequis

  • Connaissance de base de la ligne de commande
  • Aisance dans la gestion des fichiers sur votre système
  • Aucune expérience préalable de Git ou GitHub n'est nécessaire

Objectifs pédagogiques

  • Comprendre les principes du contrôle de version avec Git
  • Utiliser au quotidien les commits, branches, fusions et rebases
  • Collaborer grâce aux Pull Requests et aux revues de code sur GitHub
  • Adopter de bonnes pratiques d'équipe sur un projet Git
  • Comprendre le fonctionnement interne de Git pour résoudre des problèmes en autonomie

Programme

  1. Présentation de Git : ce qu'il fait et ce qu'il ne fait pas
  2. Installation et configuration
  3. Dépôts locaux et distants
  4. Cycle de travail : add, commit, push, pull
  5. Création et gestion des branches
  6. Fusion des branches et résolution des conflits
  7. Principe du rebase
  8. Découverte de l'interface GitHub
  9. Création et relecture de Pull Requests
  10. Aperçu des Issues, Discussions et Projects
  11. Comparaison entre GitHub Flow et Git Flow
  12. Commandes utiles et astuces du quotidien
  13. Bonnes pratiques pour les messages de commit et le travail en équipe
  14. Atelier pratique : créer, collaborer et fusionner une première Pull Request

Modalités

La formation repose sur la pratique et l'interactivité. Chaque notion est d'abord expliquée simplement, puis mise en application lors d'exercices guidés sur un dépôt collaboratif.
